# RideX

AI-powered ride booking platform built with Python microservices.

## Architecture

- API Gateway
- User Service
- Driver Service
- Ride Service
- Matching Service
- Pricing Service
- Payment Service
- Notification Service
- Rating & Safety Service

## Technology

- Python
- FastAPI
- Docker
- Docker Compose
- PostgreSQL
- Redis
- Ansible
- AI/GenAI

## Development

This project is developed using GitHub Codespaces.
